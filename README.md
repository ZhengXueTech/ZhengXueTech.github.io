# 何政學｜zhengxuetech.github.io

新北市立中正國中生活科技教師何政學的個人網站：作品、經歷與教學工具入口。

## 網站內容
| 檔案 | 用途 |
|---|---|
| `index.html` | 個人首頁 |
| `links.js` | 短網址清單（`zhengxuetech.github.io/代碼`） |
| `404.html` | 短網址轉址；找不到的網址也會顯示這頁 |
| `links.html` | 短網址管理頁（不公開收錄）：新增、檢查重複、產生 QR code |
| `lib/qrcode.js` | QR code 元件（qrcode-generator，MIT 授權） |
